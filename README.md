# Arena FreeStyle Login

Interfaz de login creada con React, Vite y TypeScript.

## Stack

- React + Vite + TypeScript
- React Router DOM
- Tailwind CSS v4
- React Hook Form
- Zod
- Tabler Icons

## Estructura principal

- Ruta principal: `/login`
- Pagina: `src/pages/login/Login.tsx`
- Componentes del login: `src/pages/login/components`
- Validaciones: `src/pages/login/loginSchemas.ts`
- Imagenes del login: `public/login`

## Assets

- Logo e iconos: `.png`
- Fondo: `.webp`
- Conversor recomendado: https://squoosh.app/

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run build
```
